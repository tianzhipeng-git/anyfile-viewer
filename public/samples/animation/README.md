# Animation samples

[![Open in Anyfile](https://www.anyfile.top/brand/open-in-anyfile.svg)](https://www.anyfile.top/en/view#file=https%3A%2F%2Fwww.anyfile.top%2Fsamples%2Fanimation%2Fanimated.apng)

Preview the APNG sample in your browser. Pause and frame controls are available
when the browser supports frame decoding. [APNG guide and limits](https://www.anyfile.top/en/formats/apng).

These images were generated from original color gradients by this project's
`viewer/plugins/browser-image/scripts/generate-examples.mjs` using ImageMagick
and libavif. They contain no third-party artwork and are distributed under the
repository's Apache-2.0 license. Source and generation instructions:
https://github.com/tianzhipeng-git/anyfile-viewer
