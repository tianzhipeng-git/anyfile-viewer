# SketchUp sample

`chair-and-table.skp` is a 30,748-byte legacy SketchUp v17 model from OpenSKP.
It shows a chair and table with component placement and basic materials; it is
not an architectural walkthrough scene.

- Source: [OpenSKP sample at commit bb34bad4e2059d8ff3dc693eb50ac632a39f7a33](https://github.com/iamahsanmehmood/openskp/blob/bb34bad4e2059d8ff3dc693eb50ac632a39f7a33/examples/web-viewer/samples/chair_and_table.skp).
- Copied unchanged from `viewer/plugins/mesh-3d/examples/chair-and-table.skp`.

The project's SKP parser and Three.js adapter tests verify geometry, component
placement and dimensions for this file. A passing decoder test does not verify
all SketchUp versions or browser graphics behavior. Viewing requires WebGL 2.
