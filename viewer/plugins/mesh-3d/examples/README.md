# Fixed 3D fixtures

Generated by `node generate.mjs`; original project-authored tetrahedron coordinates,
distributed under this repository's Apache-2.0 license. The generated tetrahedron fixtures contain no third-party model data.
The same four faces are encoded as ASCII/binary STL, OBJ, OFF, ASCII PLY,
GLB and glTF with an external buffer. Tests generate malformed and nonfinite variants.
These fixtures establish geometry and loading behavior, not advanced format fidelity.

Additional authored fixtures: animated.gltf (translation animation), missing-texture.gltf (optional-resource degradation), material.obj/material.mtl (local material association), binary-little.ply and binary-big.ply (indexed RGB mesh). These are reproducible through the same generator.

## SketchUp samples

The SKP files below are from [OpenSKP](https://github.com/iamahsanmehmood/openskp/tree/bb34bad4e2059d8ff3dc693eb50ac632a39f7a33), pinned to commit `bb34bad4e2059d8ff3dc693eb50ac632a39f7a33`, under its MIT license (see `licenses/openskp/1.3.0/LICENSE` at the repository root):

- `chair-and-table.skp`: `examples/web-viewer/samples/chair_and_table.skp`, legacy v17; component placement and materials.
- `chapel-v17.skp`: `packages/typescript/tests/fixtures/capilla_quiroz_v17.skp`, legacy v17; three embedded textures.
- `model-v25.skp`: `packages/typescript/tests/fixtures/SU_File.skp`, VFF v25; compressed modern container.

Parser tests cover all three through OpenSKP into embedded GLB; the chair/table fixture additionally goes through the Three.js adapter with dimension assertions. Real Chrome/WebGL visual acceptance remains pending.
