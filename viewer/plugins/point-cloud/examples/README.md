# Fixed fixtures

Project-authored tetrahedron / helix fixtures under Apache-2.0.
Regenerate from the repository root with `python3 scripts/generate-3d-examples.py`.
The small fixtures verify geometry and loading, not the full format specification.

helix.las uses LAS 1.2 point format 0 with survey-sized XYZ offsets, authored by scripts/generate-3d-examples.py. Its expected local extents are 2 × 2 × 4.999.
