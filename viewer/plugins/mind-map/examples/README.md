# Mind map samples

Original synthetic, redistributable fixtures under the repository Apache-2.0 license:

- `planning.mm`: FreeMind XML, also the basic Freeplane interchange structure.
- `planning.xmind`: modern XMind JSON in a deflated ZIP.
- `planning-legacy.xmind`: legacy XMind XML in a deflated ZIP.
- `planning.mmap`: MindManager namespaced Document.xml in a deflated ZIP.

Each map has the bilingual root “项目计划 / Project plan” and three branches. These minimal format fixtures are for parser/UI smoke testing; they were not exported by the original desktop software. They do not include full application metadata or claim desktop round-trip compatibility.
