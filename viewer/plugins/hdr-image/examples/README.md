# HDR & OpenEXR Sample Files

- `all-half-values.exr` — Official Academy Software Foundation (`AcademySoftwareFoundation/openexr-images`, `TestImages/AllHalfValues.exr`, BSD-3-Clause), 256×256 OpenEXR covering all 16-bit half-float bit patterns.
- `studio-gradient.hdr` — Original 64×32 equirectangular Radiance RGBE HDR sample (Apache-2.0) with a high-dynamic-range sun peak (>16.0 linear luminance) for testing exposure, tone mapping, and 360° sphere projection.
