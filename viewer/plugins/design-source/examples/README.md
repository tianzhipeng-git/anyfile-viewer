# Design Source Examples

All sample files in this directory are real documents exported by Figma and Sketch, redistributed under the MIT License:

- `OpenFigs.fig` — Real Figma `.fig` archive (Kiwi v106, Zstandard-compressed data chunk, thumbnail, and multi-layer scenegraph). Source: [OpenFig-org/openfig-core](https://github.com/OpenFig-org/openfig-core) (MIT License).
- `circle.fig` — Minimal real Figma `.fig` archive containing vector/shape geometry and metadata. Source: [OpenFig-org/openfig-core](https://github.com/OpenFig-org/openfig-core) (MIT License).
- `artboard-backgrounds.sketch` — Real Sketch `.sketch` document containing pages, artboards with background colors, and embedded preview thumbnail. Source: [sketch-hq/sketch-assistants](https://github.com/sketch-hq/sketch-assistants) (MIT License).
- `colored-strings.sketch` — Real Sketch `.sketch` document containing rich text layers (`attributedString`) with font and color styling. Source: [sketch-hq/sketch-assistants](https://github.com/sketch-hq/sketch-assistants) (MIT License).
