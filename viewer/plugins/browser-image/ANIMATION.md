# 可控制的动画查看（S3）

2026-09-29：在现有 `browser-image` 内实现 GIF、APNG、动画 WebP 与 AVIF 的统一播放模块。没有新增重叠插件、第三方解码器或公共运行时资产；manifest / probe / 静态图片保持原有加载边界，播放器动态导入。

## 工作方式

- 先按实际文件头识别 MIME，再通过 `ImageDecoder.isTypeSupported()` 检查环境。不支持时保留 `<img>` 预览并明确说明没有帧控制。
- 可控路径使用 `preferAnimation: true`，完整读取有输入上限的文件，待元数据完成后取得准确帧数。浏览器处理帧间混合和处置，Canvas 每次清空后绘制已合成帧。
- 一次只解码一帧；`VideoFrame` 在绘制后立即 `close()`。按帧索引请求支持向前与向后步进，无应用层全帧缓存。
- 解码器内部可能缓存帧：输入最大 128 MiB，单边 8192 像素，单帧 16 Mi 像素，帧画布面积之和 64 Mi 像素，最多 10,000 帧。合计面积预算按完整画布计算，对应约 256 MiB 的全帧 RGBA8 像素总量，并非总进程内存保证（解码器还可能有其他缓存或更高位深缓冲）。超过预算报 `resource-limit`，不悄悄丢帧。
- 调速按剩余帧时长重算下一次调度，保持当前帧与循环进度；解码中的速率变化在后续调度生效，不创建并行解码。
- 时长来自解码器，单位由微秒转换为毫秒；标签为“解码帧时长”，可能含浏览器对极短延迟的规范化。缺失时显示未知且禁用自动播放，仍能逐帧。零时长帧调度至少让出 1 ms，展示仍是 0 ms。
- `ImageTrack.repetitionCount` 是首次播放之后的重复次数；界面显示总播放次数（加 1），Infinity 显示无限。按有限次数播放后停留末帧，重新播放从首帧开始。手动步进会暂停并重置已完成的重复次数。
- 开启 reduced-motion 时默认暂停；页面隐藏或设置切换为 reduced-motion 时暂停，返回页面不自动恢复。原生 `<img>` 回退不具备这些帧级控制。
- 取消和销毁会关闭 decoder、清除计时器与监听器、销毁视口并释放 Canvas；旧异步结果不能绘制。

API 语义参考：[WebCodecs Image Decoding](https://www.w3.org/TR/webcodecs/#image-decoding)。各浏览器是否支持 API 和特定格式分别判断，不以浏览器名称推测支持。

## 使用与样例

手机或电脑进入格式页后选择本地文件；也可点击“打开文件夹”右侧的“样例”，展开动画样例文件夹并选择 APNG / GIF / WEBP / AVIF 文件。暂停后用上一帧、下一帧查看，再点播放继续；速度菜单提供 0.25×、0.5×、1×、1.5×、2×、4×，暂停与逐帧不重置所选速度。手机空间紧张时可收起文件栏。格式页提供样例下载和相同说明。

公开样例位于 `public/samples/animation/`，来自本插件 `examples/animated.*`；都是项目原创渐变，无第三方素材。重新生成后同步复制，不能用测试替换文件覆盖公开版本。内置样例由调用方标记 `file_source=sample`，不依赖文件名。

用户点击控件通过可选协议回调 `reportInteraction` 发送有限枚举，每次打开每种 action 去重；自动播放不发送。GA4 `action` 维度及线上事件仍待发布后确认，见产品测量文档。

## 验证记录

- `pnpm lint`、`pnpm build`（含分包与资产检查）、107 项应用测试及 61 项图片插件测试通过。
- 自动测试：四格式接入、有限循环、暂停/步进/恢复、末帧停留与重播、缺失时长、异步取消后释放、重复销毁、损坏文件、输入与展开预算；新增统计测试区分主动操作、样例和自动播放。
- 真实 Chrome（本机，生产构建）：四种公开样例均显示可控 Canvas、正确帧数、解码时长与无限循环；实际点击暂停及逐帧通过。APNG 恢复播放通过。
- 真实 Chrome 定向样例 `disposal-finite.apng`：4 帧、500 ms、总播放 2 次后停在第 4 帧；放大逐帧目视确认 OVER 半透明叠加、PREVIOUS 恢复红色、BACKGROUND 清空左下、SOURCE 透明替换右下。
- 样例与倍速追加验收：真实 Chrome 确认“打开文件夹”右侧的样例按钮、可折叠样例文件夹、文件切换和重新打开；0.25× 选项在暂停与逐帧后保留，界面解码帧时长不变。调速过程中剩余时长与解码竞态由单元测试覆盖。
- Chrome 390 × 844 视口：控件换行可操作，收起文件栏后画布仍可用。这是桌面窄屏测试，不代表实体手机浏览器验收。
- 未完成：实体 iOS / Android、非 Chromium 的原生回退真实验收、特殊 AVIF profile/HDR/方向与超大文件实测、上线 GA4 收数。当前不声明这些组合已经验证。
