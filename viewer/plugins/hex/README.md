# 十六进制查看器 (`hex-viewer`)

以十六进制 + ASCII 形式预览任意二进制文件的兜底查看器。

## 基本介绍

- **插件 ID**：`hex-viewer`
- **支持格式**：`*`（任意扩展名，`application/octet-stream`）
- **能力**：偏移地址、十六进制字节、可打印字符列；虚拟滚动支持大文件
- **定位**：当没有其他专用插件匹配时，作为通用二进制预览 fallback

## 实现原理

1. **虚拟滚动**（`src/index.ts`）
   - 每行 16 字节（`BYTES_PER_ROW = 16`）
   - 根据视口高度计算可见行数，仅读取并渲染可见区域 + overscan（±5 行）
   - 虚拟高度上限约 800 万像素（`MAX_VIRTUAL_HEIGHT`）；超出时滚动条按比例映射到文件全文

2. **按需读取**
   - 通过 `file.slice(start, end).stream()` 流式读取当前窗口字节
   - 每次滚动/resize 触发 `renderVisibleRows()`，前一次读取可被 `AbortController` 取消

3. **格式化**
   - 偏移：十六进制，宽度随文件大小自适应（至少 8 位）
   - 十六进制：8+8 分组，不足补空格
   - ASCII：可打印字符（0x20–0x7E）直接显示，其余为 `·`

4. **UI**
   - CSS Grid 三列（偏移 / 十六进制 / 文本）
   - 粘性表头；等宽字体；支持 `ResizeObserver`

## 依赖

| 包 | 用途 |
|---|---|
| `@anyfile/viewer-protocol` | 插件协议 |

无第三方渲染库，纯浏览器 API 实现。

## 已知限制

- 只读预览，不支持编辑、搜索、跳转地址
- ASCII 列仅支持基本拉丁可打印字符，无 UTF-8 多字节解码
- 极大文件（数 GB）虚拟滚动映射后，精确跳转到文件末尾的滚动体验较粗
- 每次滚动触发异步读取，快速滚动可能出现短暂空白或闪烁
- 不提供结构化解码（PE/ELF/Mach-O 等），仅原始字节视图
- 空文件显示提示，不报错
