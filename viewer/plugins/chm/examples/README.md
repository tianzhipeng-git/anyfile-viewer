# CHM Example Fixtures

All files in this directory are original CC0-1.0 test fixtures generated by [../scripts/generate-examples.py](../scripts/generate-examples.py) and cross-verified against C `chmlib`.

| File | Purpose |
|---|---|
| `sample-handbook.chm` | LZX Verbatim-compressed CHM with nested `.hhc` contents tree, `.hhk` index, CSS, embedded PNG, percent-encoded paths with spaces, `#SYSTEM`/`#TOPICS`/`#URLTBL`/`#URLSTR`, internal links, fragments, and self `ms-its:` link |
| `cjk-gbk.chm` | GBK-encoded (`LCID 0x0804`) CHM with non-ASCII paths, Chinese `.hhc` labels, LZX uncompressed block, and embedded BMP icon |
| `malicious-sandbox.chm` | Security and resilience fixture containing `<script>`, ActiveX `<object>`, `<iframe>`, `<form>`, remote image/URLs, `javascript:` link, cross-CHM `ms-its:other.chm::/...` link, and a missing local image |
| `corrupt-loop.chm` | Negative fixture: PMGL directory chunk `nextChunk` self-loop (`invalid-file`) |
| `truncated-header.chm` | Negative fixture: truncated 64-byte ITSF header |
| `disguised-text.chm` | Negative fixture: plain text with `.chm` extension |
